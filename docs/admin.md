Administrative commands and permission nodes for 1b1v (Orion).

---

## Commands

* **`/1b1v reload`**  
  Reloads plugin configuration files and caches without restarting the server.  
  *Permission:* `1b1v.admin.reload`

* **`/1b1v wiki`**  
  Sends an interactive link to this documentation website in chat.  
  *Permission:* `1b1v.wiki`
